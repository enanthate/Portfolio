# Personal Resume Website | Сайт-резюме

## Description / Описание
This project was created as part of a laboratory assignment for Tambov State Technical University (TSTU). It is a single-page personal resume website designed to showcase basic web development skills.

Проект создан в рамках лабораторной работы для Тамбовского государственного технического университета (ТГТУ). Это одностраничный сайт-резюме, демонстрирующий базовые навыки веб-разработки.

## Features / Возможности
- **Responsive Design:** Adapts to different screen sizes.
- **Theme Switcher:** Toggle between Dark and Light modes.
- **Language Support:** Switch content between Russian and English.
- **Animations:** Smooth scrolling and fade-in effects on scroll using Intersection Observer.
- **Typing Effect:** Dynamic text animation in the hero section.

## Tech Stack / Технологии
- HTML5
- CSS3 (Flexbox, Transitions, Animations)
- JavaScript (Vanilla JS, DOM Manipulation)

## Structure / Структура
- `index.html` - Main structure and content.
- Styles are embedded in `<style>` for simplicity (single-file deployment).
- Scripts are embedded in `<script>` for handling logic.
